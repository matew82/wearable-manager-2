Wearable Manager Wardrobe - Undo/Redo verification
2026-10-13

Implemented
- Scene metadata now uses a hidden native undoable string property. Legacy metadata remains readable; an authoritative null masks unregistered legacy records.
- Recovery, ownership, registration and property-override state follow scene Undo/Redo. Support and membership readers use the same state.
- Session hand-pose baselines follow Undo/Redo without becoming persistent scene metadata. Both hands, child bones and Pose Controls are covered.
- Removing a pose-owning outfit through partial/bulk/single/transfer operations restores its hand baseline; a retained outfit keeps its pose.
- GeoShell material values, maps, named UVs and property attributes are restored after native Undo/Redo recreates graft surfaces. A native callback remains available after the invoking script ends.
- Successfully compensated failed actions add no Undo entry. Incomplete compensation retains its Undo group.
